# ElderEase Banking App

## Overview

ElderEase Banking App is a desktop banking application developed with a focus on accessibility and ease of use for elderly users. The system provides essential banking functionalities through a simple and intuitive interface designed to reduce complexity and improve the user experience.

## Features

* User-friendly banking interface
* Account management
* Deposit functionality
* Withdrawal functionality
* Balance enquiry
* Transaction management
* Accessible design for elderly users

## Problem Statement

Many banking applications can be difficult for elderly users to navigate due to complex interfaces and overwhelming functionality. ElderEase was designed to address this challenge by providing a simplified banking experience that prioritizes usability and accessibility.

## Technologies Used

* C++
* Qt Framework
* Object-Oriented Programming (OOP)

* Encapsulation
